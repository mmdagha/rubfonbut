# ربات سرگرمی پیشرفته روبیکا

ربات چندبازیه با معماری ماژولار برای پیام‌رسان روبیکا (Bot API رسمی)

## امکانات

- **حقیقت یا جرات** (بیش از ۱۲۰ حقیقت + ۱۲۰ جرات)
- **ترجیح می‌دادی؟** (Would You Rather)
- **سنگ کاغذ قیچی** (با سیستم امتیاز)
- **حدس کلمه** (با امتیاز برای کسی که زودتر حدس بزنه + رتبه‌بندی)
- **جوک تصادفی**
- **رتبه‌بندی بازیکنان** در هر گروه

## نحوه استفاده

1. توکن ربات را از `@BotFather` در روبیکا بگیرید.
2. فایل `config.js` را باز کنید و توکن را جایگزین کنید:
   ```js
   export const TOKEN = "توکن_شما";
   ```
3. ربات را اجرا کنید:
   ```bash
   node bot.js
   ```
4. در گروه یا چت خصوصی دستور زیر را بفرستید:
   ```
   /روبات
   ```

## نکات

- از روش Long Polling استفاده می‌کند (نیازی به سرور عمومی و SSL نیست).
- امتیازها در حافظه نگهداری می‌شوند (با ری‌استارت ربات ریست می‌شوند).
- برای اضافه کردن حقیقت/جرات بیشتر، فقط فایل‌های JSON را ویرایش کنید.

## توسعه بعدی پیشنهادی

- ذخیره امتیازها در فایل یا دیتابیس
- گرفتن نام واقعی کاربر با `getChat`
- بازی‌های بیشتر (مافیا ساده، حدس عدد و ...)
- حالت تورنمنت
